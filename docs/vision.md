# Vision

## Mission

Build a lightweight, offline-first fitness tracking application that provides reliable GPS activity tracking without the complexity of modern fitness social platforms.

## Goals

- Fast startup
- Battery efficient
- Works offline
- Simple interface
- Privacy-first
- Easy to use

## Target Users

- Casual runners
- Walkers
- Cyclists
- Users with low-end Android devices
- Users who only want activity tracking

## Core Principles

- Performance over flashy UI
- Simplicity over feature bloat
- Offline before cloud
- Local data ownership
- Incremental development

## Non-Goals

Stride is NOT intended to be:

- A social network
- A training coach
- A premium subscription platform
- A Strava clone

The focus is reliable activity tracking.
